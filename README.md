# 🚀 Learning C++ & DSA

> A structured learning repository documenting my journey from **C++ fundamentals to Object-Oriented Programming, STL, and Data Structures & Algorithms**.

This repository contains my notes, code examples, practice programs, and problem-solving progress while learning C++ and DSA.

---

## 📚 Learning Roadmap

### 🟢 C++ Fundamentals

| # | Module | Topics |
|---|---|---|
| 01 | **Introduction to C++** | Installation & setup, compiler, VS Code, boilerplate, first program |
| 02 | **Fundamentals** | Variables, data types, comments, syntax, identifiers, constants, literals, `sizeof`, type conversion, operators, input/output |
| 03 | **Control Flow Statements** | `if`, `if-else`, nested `if`, `else-if`, `switch`, ternary operator, `for`, `while`, `do-while`, `break`, `continue`, nested loops, pattern programming |
| 04 | **Functions** | Function declaration, definition, calling, return types, parameters, call by value, call by reference, default arguments |
| 05 | **Arrays** | 1D arrays, initialization, traversal, memory layout, `sizeof`, array-based problem solving |
| 06 | **Strings** | String basics, input, manipulation, traversal, common string operations |
| 07 | **Pointers** | Addresses, pointers, dereferencing, pointer operations, pointers with functions |
| 08 | **Dynamic Memory Allocation** | Dynamic memory, `new`, `delete`, heap allocation, memory management |
| 09 | **Structures & Unions** | `struct`, `union`, custom data types, memory behavior |

---

### 🔵 Object-Oriented Programming

| # | Module | Topics |
|---|---|---|
| 10 | **Classes & Objects** | Classes, objects, members, methods |
| 11 | **Constructors** | Default, parameterized, copy constructors |
| 12 | **Destructor** | Object destruction and resource cleanup |
| 13 | **Encapsulation** | Access modifiers, data hiding, getters and setters |
| 14 | **Static Members** | Static variables, static functions, class-level members |
| 15 | **Inheritance** | Base/derived classes, types of inheritance |
| 16 | **Polymorphism** | Function overloading, overriding, runtime polymorphism |
| 17 | **Abstraction** | Abstract classes, interfaces, hiding implementation details |
| 18 | **Exception Handling** | `try`, `catch`, `throw`, error handling |
| 19 | **STL** | Containers, iterators, algorithms, and the Standard Template Library |
